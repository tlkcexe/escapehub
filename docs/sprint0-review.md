### 4.3 Τεχνική υποδομή και CI

Η αρχική τεχνική υποδομή του EscapeHub βασίζεται στις
παρακάτω τεχνολογίες:

- Java 21 και Spring Boot για το backend.
- Maven για τη διαχείριση και μεταγλώττιση του project.
- PostgreSQL για την αποθήκευση δεδομένων.
- JUnit και Spring Boot Test για τους αυτοματοποιημένους ελέγχους.
- GitHub Actions για το Continuous Integration (CI).

Στο αποθετήριο υπάρχουν τα αρχεία:

- `pom.xml`: Ρυθμίσεις Maven και εξαρτήσεις του project.
- `.github/workflows/ci.yml`: Workflow για build,
  tests και στατική ανάλυση.
- `.github/workflows/pr-checks.yml`: Έλεγχος σύνδεσης
  των Pull Requests με GitHub Issues.

Το CI έχει ρυθμιστεί να εκτελεί το `mvn verify`,
το οποίο περιλαμβάνει μεταγλώττιση, tests και
ελέγχους στατικής ανάλυσης.### 4.3 Τεχνική υποδομή και CI

## 5. Έκδοση v0.1.0

Η έκδοση v0.1.0 αποτελεί τον στόχο παράδοσης
του Sprint 0.

Στο παρόν στάδιο, το project χρησιμοποιεί
την έκδοση ανάπτυξης `0.1.0-SNAPSHOT`.

Για την ολοκλήρωση της έκδοσης απαιτούνται:

- Επιτυχής εκτέλεση του CI.
- Ενσωμάτωση των απαραίτητων Pull Requests.
- Ενημέρωση του CHANGELOG.
- Δημιουργία Git tag `v0.1.0`.
- Δημοσίευση GitHub Release.
- Δημιουργία του αντίστοιχου Docker image.

Η τελική κατάσταση της έκδοσης θα επιβεβαιωθεί
πριν από την παρουσίαση του Sprint Review.
