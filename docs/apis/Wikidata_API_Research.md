# Διερεύνηση Wikidata API

**Εργασία:** EscapeHub

**User Story:** US-08

**Sprint:** 0


## 1. Σκοπός

Σκοπός της εργασίας μας ήταν να γνωρίσουμε τις βασικές λειτουργίες του Wikidata API και να δούμε πώς μπορούμε να το χρησιμοποιήσουμε για να παίρνουμε πραγματικές πληροφορίες που θα χρειαστούν στους γρίφους του EscapeHub.

## 2. Δυνατότητες του API

Το Wikidata περιέχει πληροφορίες για πρόσωπα, βιβλία, τοποθεσίες, ιστορικά γεγονότα και πολλά άλλα.

Κάθε οντότητα έχει ένα μοναδικό ID που ξεκινάει από `Q`, ενώ οι ιδιότητές της έχουν IDs που ξεκινάνε από `P`.

Οι βασικές λειτουργίες που εξετάσαμε είναι:

- `wbsearchentities`: Μπορούμε να ψάξουμε μια οντότητα με βάση το όνομά της.
- `wbgetentities`: Μπορούμε να πάρουμε πληροφορίες για μια συγκεκριμένη οντότητα.
- `wbgetclaims`: Μπορούμε να πάρουμε συγκεκριμένες ιδιότητες μιας οντότητας.

Υπάρχει επίσης το SPARQL, με το οποίο μπορούμε να κάνουμε πιο σύνθετες αναζητήσεις.

## 3. Δοκιμές API

Για τις δοκιμές χρησιμοποιήσαμε HTTP GET requests μέσω του browser, με παράδειγμα τη συγγραφέα Mary Shelley.

| Δοκιμή                       | Αποτέλεσμα                     |
| ---------------------------- | ------------------------------ |
| Αναζήτηση Mary Shelley       | Βρήκαμε το ID `Q47152`         |
| Ανάκτηση πληροφοριών         | Πήραμε δεδομένα σε μορφή JSON  |
| Ημερομηνία γέννησης (`P569`) | 30/08/1797                     |
| Σύζυγος (`P26`)              | `Q93343` — Percy Shelley       |
| Αναζήτηση ανύπαρκτου ID      | Πήραμε σφάλμα `no-such-entity` |

Από αυτές τις δοκιμές είδαμε ότι μπορούμε να βρούμε απλές πληροφορίες, αλλά και σχέσεις ανάμεσα σε διαφορετικά πρόσωπα.

## 4. Μορφή απαντήσεων

Στις δοκιμές μας ζητήσαμε από το API να επιστρέψει τις πληροφορίες σε μορφή JSON.

Μέσα στο JSON συναντήσαμε πεδία όπως:

- `id`: Το ID της οντότητας.
- `label`: Το όνομα.
- `description`: Μια σύντομη περιγραφή.
- `claims`: Οι ιδιότητες της οντότητας.
- `datavalue`: Η τιμή μιας ιδιότητας.

Οι πληροφορίες μπορεί να είναι ημερομηνίες, κείμενο ή IDs άλλων οντοτήτων.

Είδαμε επίσης ότι όταν ζητήσαμε ένα ID που δεν υπάρχει, το API επέστρεψε μήνυμα σφάλματος.

## 5. Περιορισμοί και όροι χρήσης

Το Wikidata API είναι δωρεάν, αλλά υπάρχουν κάποιοι περιορισμοί στη χρήση του.

Για να το χρησιμοποιούμε σωστά, καλό είναι:

- Να μη στέλνουμε υπερβολικά πολλά αιτήματα ταυτόχρονα.
- Να χρησιμοποιούμε ένα αναγνωρίσιμο `User-Agent`.
- Να αποθηκεύουμε προσωρινά πληροφορίες που χρειαζόμαστε συχνά, ώστε να μη ζητάμε συνέχεια τα ίδια δεδομένα.
- Αν εμφανιστεί σφάλμα HTTP 429, να περιμένουμε πριν στείλουμε νέο αίτημα.

Δεν υπάρχει ένα σταθερό όριο αιτημάτων που να ισχύει για όλες τις περιπτώσεις.

Τα δεδομένα του Wikidata διατίθενται με άδεια CC0, επομένως μπορούμε να τα χρησιμοποιούμε ελεύθερα.&#x20;

## 6. Συμπέρασμα

Από τις δοκιμές μας είδαμε ότι το Wikidata API μπορεί να χρησιμοποιηθεί στο EscapeHub για να βρίσκουμε πραγματικές πληροφορίες και να τις αξιοποιούμε στους γρίφους.

Για παράδειγμα, μπορούμε να δημιουργήσουμε έναν γρίφο στον οποίο ο παίκτης πρέπει να βρει τον σύζυγο της Mary Shelley.

Οι δοκιμές που κάναμε είναι ενδεικτικές. Όταν αποφασίσουμε τους τελικούς γρίφους της αποστολής, θα χρειαστεί να δοκιμάσουμε και τα αντίστοιχα ερωτήματα.
