# US-09 - Open Library API Research

## 1. Σκοπός

Μελέτη του Open Library API για την αξιοποίηση πληροφοριών
σχετικά με βιβλία και συγγραφείς στους γρίφους του EscapeHub.

## 2. Δυνατότητες

- Αναζήτηση βιβλίων μέσω τίτλου και συγγραφέα.
- Αναζήτηση συγγραφέων μέσω ονόματος.
- Ανάκτηση πληροφοριών μέσω μοναδικών IDs.
- Ανάκτηση ημερομηνιών, περιγραφών και εκδόσεων.
- Διασύνδεση με άλλες υπηρεσίες, όπως το Wikidata.

Οι δοκιμές πραγματοποιήθηκαν μέσω HTTP GET requests
στον browser, με αποκρίσεις σε μορφή JSON.

## 3. Δοκιμές API

### Test 1 - Αναζήτηση βιβλίου

https://openlibrary.org/search.json?title=Frankenstein&limit=3

Αποτελέσματα: 2156

- Τίτλος: Frankenstein; or, The Modern Prometheus
- Συγγραφέας: Mary Shelley
- Work ID: OL450063W
- Έτος πρώτης έκδοσης: 1818

Αποτέλεσμα: Επιτυχής αναζήτηση.

### Test 2 - Φιλτράρισμα αποτελεσμάτων

https://openlibrary.org/search.json?title=Frankenstein&author=Mary%20Shelley&fields=key,title,author_name,first_publish_year&limit=3

Με τη χρήση των παραμέτρων author και fields,
τα αποτελέσματα μειώθηκαν σε 530 και επιστράφηκαν
μόνο τα ζητούμενα πεδία.

Αποτέλεσμα: Επιτυχές φιλτράρισμα.

### Test 3 - Αναζήτηση συγγραφέα

https://openlibrary.org/search/authors.json?q=Mary%20Shelley&limit=3

Αποτελέσματα: 17

- Όνομα: Mary Shelley
- Author ID: OL25342A
- Ημερομηνία γέννησης: 30 August 1797
- Ημερομηνία θανάτου: 1 February 1851

Αποτέλεσμα: Επιτυχής αναζήτηση.

### Test 4 - Ανάκτηση έργου μέσω ID

https://openlibrary.org/works/OL450063W.json

Επιστράφηκαν ο τίτλος, η περιγραφή, οι θεματικές
κατηγορίες, το ID του συγγραφέα και το Wikidata ID
του έργου (Q150827).

Αποτέλεσμα: Επιτυχής ανάκτηση.

### Test 5 - Ανάκτηση συγγραφέα μέσω ID

https://openlibrary.org/authors/OL25342A.json

Επιστράφηκαν τα προσωπικά στοιχεία, η βιογραφία
και το Wikidata ID της Mary Shelley (Q47152).

Το Wikidata ID συμφωνεί με το αποτέλεσμα
της έρευνας του US-08.

Αποτέλεσμα: Επιτυχής ανάκτηση.

### Test 6 - Ανύπαρκτο ID

https://openlibrary.org/works/OL999999999999W.json

Απόκριση:

{
    "error": "notfound",
    "key": "/works/OL999999999999W"
}

Αποτέλεσμα: Επιστροφή μηνύματος σφάλματος σε JSON.
Ο HTTP status code δεν ελέγχθηκε.

## 4. Περιορισμοί και όροι χρήσης

- Δημόσιο και δωρεάν API για περιορισμένο όγκο αιτημάτων.
- Βασικό όριο 1 request ανά δευτερόλεπτο.
- Όριο 3 requests ανά δευτερόλεπτο για εφαρμογές
  που δηλώνουν κατάλληλα την ταυτότητά τους.
- Συνιστάται caching των αποκρίσεων.
- Για μαζική ανάκτηση δεδομένων παρέχονται Data Dumps.
- Τα δεδομένα καταλόγου διατίθενται ανοικτά, με τις
  συνεισφορές να υπόκεινται σε CC0 1.0.
- Τα πλήρη κείμενα και εξώφυλλα ενδέχεται να
  υπόκεινται σε διαφορετικά δικαιώματα χρήσης.

## 5. Παρατηρήσεις

Κατά τις δοκιμές εντοπίστηκαν:

- Πολλαπλές εγγραφές συγγραφέων με το ίδιο όνομα
  αλλά διαφορετικά IDs.
- Ασυνέπεια μεταξύ του first_publish_year (1818)
  και του first_publish_date (2006) για το Frankenstein.
- Δυνατότητα διασύνδεσης με το Wikidata μέσω
  κοινών αναγνωριστικών.

Επομένως, απαιτείται διασταύρωση των δεδομένων
και χρήση συγκεκριμένων IDs για τους γρίφους.

## 6. Συμπέρασμα

Το Open Library API μπορεί να αξιοποιηθεί στο
EscapeHub για γρίφους σχετικούς με βιβλία,
συγγραφείς και ημερομηνίες έκδοσης.

Οι δοκιμές αναζήτησης βιβλίου και συγγραφέα
ολοκληρώθηκαν επιτυχώς.

Η ενσωμάτωση στο backend θα πραγματοποιηθεί
σε επόμενο στάδιο του project.
