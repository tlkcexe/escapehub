# AI usage log

Σύντομο αρχείο καταγραφής της χρήσης εργαλείων AI. Ενημερώνεται **σε κάθε sprint**,
όχι μόνο στο τέλος. Δεν καταγράφουμε κάθε προτροπή, μόνο τις σημαντικές περιπτώσεις.

**Κανόνες:** δεν εισάγονται κωδικοί, API keys ή προσωπικά δεδομένα σε AI. Την ευθύνη για την
ορθότητα την έχει η ομάδα. Το merge εγκρίνεται πάντα από μέλος της ομάδας.

**Σε κάθε sprint καταγράφεται ΤΟΥΛΑΧΙΣΤΟΝ μία περίπτωση όπου η πρόταση του AI ήταν λανθασμένη,
ελλιπής ή επικίνδυνη, και πώς το εντοπίσαμε.**
