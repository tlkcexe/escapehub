# Definition of Done (DoD)

Ένα user story θεωρείται **ολοκληρωμένο** μόνο αν ισχύουν **όλα** τα παρακάτω.

## Ελάχιστα (από την εκφώνηση)
- [ ] Τα acceptance criteria του story καλύπτονται από **αυτοματοποιημένους ελέγχους που περνούν**.
- [ ] Ο κώδικας έχει ενσωματωθεί στο `main` μέσω **pull request με εγκεκριμένο review**.
- [ ] Το **CI είναι επιτυχές** (μεταγλώττιση, tests, στατική ανάλυση).
- [ ] Η σχετική τεκμηρίωση (README, OpenAPI, CHANGELOG) έχει ενημερωθεί όπου χρειάζεται.

## Δικά μας πρόσθετα
- [ ] Το PR συνδέεται με issue (`Closes #…`) και το issue έχει owner, εκτίμηση και acceptance criteria.
- [ ] Το `main` παραμένει σε εκτελέσιμη κατάσταση μετά το merge.
- [ ] Τα tests **δεν καλούν ζωντανά δημόσια APIs** (mocks / stubs / fixtures).
- [ ] Δεν υπάρχουν κωδικοί, keys ή προσωπικά δεδομένα στον κώδικα.
- [ ] Αν χρησιμοποιήθηκε AI, έχει δηλωθεί στο PR και καταγράφηκε στο AI log όπου αξίζει.
- [ ] Ο συγγραφέας και ο reviewer μπορούν να εξηγήσουν την αλλαγή.
- [ ] Για αλλαγές στο module κανόνων αποστολής: έχει τρέξει PIT και δεν επιδεινώθηκε το αποτέλεσμα.
